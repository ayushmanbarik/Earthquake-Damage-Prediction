# Earthquake-Damage-Prediction
Machine Learning Project to Predict Earthquake Damage Severity Using Building Characteristics.

## Project Overview
This project predicts the severity of earthquake damage to buildings using machine learning algorithms. The objective is to classify building damage into three categories:
- Grade 1: Low Damage
- Grade 2: Medium Damage
- Grade 3: Almost Complete Destruction
